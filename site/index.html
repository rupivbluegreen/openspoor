Four pillars

One system, end to end

01 Trace

Serialization with FF1 format-preserving encryption — random serials, unique by construction.

GS1 Digital Link and DataMatrix, EPCIS 2.0 capture and query, aggregation trees and full serial history.

02 Link

Partner directory and connections. DSCSA TI/TS exchange over HTTPS or AS2, and VRS.

B2B documents with EDI X12/EDIFACT mappers, plus node-to-node federation with signed messages.

03 Act

Governed AI agents with scoped tools, human approval gates, full audit and reversible actions.

A control tower, and an assistant that answers over your own data.

04 Comply

Country connectors for EU FMD/EMVS and Saudi RSD via an open connector SDK. Versioned, community-editable YAML rule packs.

A regulatory alert inbox with parsed rejection reasons and one-click resubmit. FSMA 204 24-hour sortable spreadsheet and EUDR due diligence statements.

Architecture

Boring, proven parts

Scroll the diagram sideways to see all of it.

  • PostgreSQL 16 with row-level security per tenant
  • Month-partitioned EPCIS event store; hash-partitioned serial state
  • Append-only audit log, hash-chained, with 21 CFR Part 11-style e-signatures
  • React 19 + Ant Design 6 UI in English, Dutch and Arabic (RTL)

Quick start

Running locally in four commands

git clone https://github.com/rupivbluegreen/openspoor
cd openspoor
docker compose -f deploy/docker-compose.yml up -d
make -C backend migrate seed run

Then open http://localhost:5173.
